# Janani Priya — Personal Portfolio

A responsive student portfolio built with **HTML, CSS, and vanilla JavaScript**.

## Files
- `index.html` — page structure and content
- `css/style.css` — responsive layout, visual design, and theme variables
- `js/script.js` — mobile menu, theme toggle, project filters, form validation, back-to-top, and active navigation
- `images/` — optional folder for your own images and project screenshots

## Before submitting
1. Check every course title, score, and completion status against your certificates.
2. Replace or update any project descriptions that do not accurately reflect your work.
3. Add screenshots you have permission to share and working links only for projects that are actually published.
4. Add your professional email or a safe contact method if your trainer expects it.
5. Test the site on mobile and desktop, including the navigation, theme toggle, filters, and demo contact form.
6. Push the complete project to a **public GitHub repository**.
7. Deploy the repository with GitHub Pages, Netlify, or another option allowed by your department.
8. Submit both the live website URL and GitHub repository URL in the college Google Form, then complete the trainer and Technical Head sign-off process.

## Run locally for testing
Open `index.html` in a browser. Local testing alone does **not** meet the live deployment requirement.

## JavaScript features
- Responsive mobile navigation menu
- Light/dark theme toggle
- Project category filters
- Contact form validation with a clear demo-only confirmation
- Back-to-top button
- Active navigation highlight and automatic footer year

The contact form does not send or store messages; it only validates fields and displays a message.
